# AetherForge Lab

Single-page site presenting an AI security research & red team laboratory: a secure agent harness
(LangChain / LangGraph + NVIDIA OpenShell), an adversarial lab, and a training bench.

Interactive, self-contained page (HTML, CSS, JS, SVG, canvas — no dependencies): attack simulator across
the Model / Harness / OpenShell layers, a step-through LangGraph example, a red team campaign loop,
training challenges and session formats.

Open `index.html` locally or via GitHub Pages.

> Illustrative content. Everything described is for authorized security research and training only.
